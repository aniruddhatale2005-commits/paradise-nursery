# Paradise Nursery

## Project Name
Paradise Nursery Shopping Application

## About the Project
Paradise Nursery is an online plant shop application where users can browse and purchase houseplants.

The application allows users to view plants by category, see plant names and prices, add plants to a shopping cart, change quantities, remove plants, and view the total cost.

## Features

- Browse houseplants
- View plant names, images, and prices
- Plants grouped into different categories
- Add plants to the shopping cart
- Dynamic shopping cart count
- Increase plant quantity
- Decrease plant quantity
- Remove plants from the cart
- Calculate total price
- Continue shopping
- Checkout message

## Technologies Used

- React
- JavaScript
- Redux
- Redux Toolkit
- CSS

## Project Goal

The goal of this project is to create a simple and user-friendly online plant shopping application using React and Redux.
